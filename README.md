# Benzaiten (弁財天) — Speculative Flow & Fluid Matter Engine

Standalone speculative instrument named after Benzaiten—the goddess of everything that flows (water, sound, time, eloquence, fluid matter).

- **Mechanism**: 2D GPGPU Navier-Stokes fluid dynamics solver + multi-scale noise domain warp + Web Audio FFT reactivity.
- **Substrates**:
  - `Mode 0`: Procedural Color Field (drifting 8-stop color ramp editor, stop locking/capture, presets).
  - `Mode 1`: Media Substrate (image / looping video / live webcam feed).
  - `Mode 2`: Hybrid Gradient Map (real-time colorization of media substrate via procedural color field).
- **Interface**: Mobile-friendly cybernetic HUD, responsive touch sliders, drag/touch fluid velocity stirring, dark mode (`U`), freeze (`Space`), drawer panel (`H`), fullscreen (`F`), media file load (`O`).

- **2026-08-05 — Claude Code**: Corrected two things that were named more accurately than they were implemented.

  **Audio bands.** The 3-band coupling split the spectrum at fixed bin indices 18 and 70 with `fftSize = 256`. At that size a bin is ~188 Hz, so the advertised 0–300 Hz / 300 Hz–3.5 kHz / 3.5–20 kHz split was really ~0–3.4 kHz / 3.4–13 kHz / 13–24 kHz — off by roughly 10x. "Bass" was swallowing the whole musical pitch range and "treble" sat above 13 kHz where most sources are near silent, so the mid and treble couplings had little to respond to. `fftSize` is now 2048 and the boundaries are derived from `audioCtx.sampleRate` at init rather than hardcoded, since a fixed bin index means a different frequency on different hardware. Verified the edges land within 2% of 300 Hz / 3.5 kHz / 20 kHz at 44.1, 48 and 96 kHz. `drawOsc` now takes the peak of the bins covered by each pixel column, because 2048 bins no longer fit one bar per bin in a 220 px canvas.

  **MHD current density.** `J_z` was computed as `(dAx + dAy) * 8.0`, a sum of central first differences, in all three places that evaluate it (`u_phys_regime = 3`, `4`, and the particle tracer vertex shader). The current density is $J_z = -\nabla^2 A_z$, a second derivative — a different operator, not a coarse version of the same one. Replaced with a 5-point Laplacian stencil in a shared `mhdField()` helper; `B` keeps its central-difference form. Both outputs are now returned dimensionless at unit RMS so the regimes scale them explicitly.

  Two consequences worth recording. The stencil step is 0.12, not smaller: the Laplacian scales as $h^2$, so at the old 0.04 step the second difference would sit only a factor of 20 above `mediump` resolution (~9% quantisation error); at 0.12 that falls to ~1% while staying well inside a noise feature. And the old `J_z` was a linear combination of `B`'s own components, which left $\mathbf{J} \times \mathbf{B}$ correlated — measured shape factor `rms|JxB| / (rms|J| rms|B|)` was 1.47–1.51, where a true Laplacian is independent of the gradient and gives 1.00. Matching the RMS of `J_z` and `B` separately therefore lost ~45% of the Lorentz force. The regimes carry an explicit `LORENTZ_DECORR` factor (1.49 / 1.467) to put it back, so every downstream expression — Alfven term, flare threshold, force weights — keeps the strength it was tuned at.
